**Cloud-Based Inventory System - **

Our project is a cloud-based inventory management system designed to make inventory tracking reliable, scalable, and easily deployable. 
Instead of simply hosting an inventory application on a single server, we use AWS cloud automation to provision the infrastructure, distribute user traffic,
monitor performance, and automatically scale the application when demand increases. 
This demonstrates how cloud computing can be used to build a practical system that remains available and responsive as the number of users grows.”

The application will be deployed on AWS using EC2, with CloudFormation for automated infrastructure deployment, Load Balancing for distributing requests, 
Auto Scaling for handling changes in workload, and CloudWatch for monitoring. The main objective is to demonstrate how cloud automation can make a practical application scalable, 
reliable, and easier to deploy.
